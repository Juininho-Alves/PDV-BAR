# BarPro

Sistema de gerenciamento de vendas e caixa desenvolvido como projeto
de teste para um comércio próprio.

## Objetivo

O objetivo do projeto é desenvolver um sistema simples para auxiliar
no controle de clientes, produtos e vendas do comércio.

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos
- Adição de produtos às vendas
- Controle de quantidade
- Consulta do resumo da compra
- Cálculo do total
- Cálculo automático do troco
- Controle de vendas pendentes
- Finalização da venda

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- Jinja2

## Banco de dados

O projeto utiliza SQLite para armazenar os dados.

Principais tabelas:

- `clientes`
- `produtos`
- `vendas`
